# Create Horse Power - CE 1.2.4

## Verification

- Added a dedicated worker-first recovery GameTest for issue #4 on both Forge 1.20.1 and NeoForge 1.21.1.
- The regression proves recovery remains queued when the recorded live crank chunk is unavailable, never force-loads that chunk, and preserves attachment plus AI-suppression ownership when the matching crank becomes available later.
- This closes the remaining test-coverage gap around the recovery behavior introduced in 1.2.1; no worker-recovery gameplay semantics are changed in this release.

## Release infrastructure

- Consolidated changelogs to one shared file per mod version at `changelog/<mod_version>.md` instead of duplicating files per Minecraft version.
- Migrated historical changelogs to the shared naming scheme.
- CI now validates the shared changelog contract before loader builds.
- GitHub Release and both CurseForge uploads now consume the same shared changelog file.
