# Create Horse Power - CE 1.2.7

## Fixes

- Fixed NeoForge path effects being lost when KubeJS is not installed. The no-KubeJS `firePathEvaluated` fallback now returns the evaluator's absolute speed/stress multipliers instead of neutral `1.0x` values.
- Preserved the `1.2.6` absolute path-hook contract consistently in both NeoForge runtime branches: KubeJS present and KubeJS absent.

## Regression coverage

- Added a NeoForge unit regression that runs without KubeJS and verifies a `2.0x` speed / `1.10x` stress path result is returned unchanged by `OptionalIntegrations.firePathEvaluated()`.
- Retained the loader GameTest coverage for the KubeJS-present runtime and the shared evaluator-mode coverage.
