# 1.20.1-1.2.0-ce.1

Initial Forge 1.20.1 Community Edition build.

- Brings the CE 1.2 architecture (shared engine, worker profiles, path evaluation modes, redstone modes, per-animal stat scaling) to Minecraft 1.20.1 Forge.
- Worker and path profiles resolve through entity/block tags and config lists; KubeJS profile registration has no Forge script entry point yet.
- Jade and KubeJS event integrations are not yet ported for 1.20.1; see the [compatibility matrix](../docs/COMPATIBILITY.md) for the exact feature status per version.
