# Create Horse Power - CE 1.2.0-ce.2

This historical changelog combines the release notes for both supported Minecraft targets into one mod-version record.

## Forge 1.20.1

This release hardens the initial Forge 1.20.1 Community Edition port and aligns its default gameplay with NeoForge 1.21.1.

### Fixes

- Restored Flywheel crank visual registration and client partial-model initialization.
- Fixed empty-hand detachment so held items no longer remove attached workers.
- Corrected 1.20.1 entity tag resource paths.
- Matched canonical built-in worker and path profiles with NeoForge while retaining live legacy config behavior for legacy tags.
- Restored Create kinetic tick ordering and added safe worker reload grace periods.
- Corrected worker yaw to follow the actual orbit movement vector, prevented vanilla AI/navigation from fighting crank movement, and restored horse eating-animation suppression while working.
- Centralized shared registrations and strengthened source/resource parity checks to catch platform omissions.
- Added required Forge bootstrap and real-horse orbit GameTests and wired them into aggregate verification.
- Ported the Jade crank HUD provider and installed Jade in the Forge development client.
- Replaced the temporary per-tick movement logger with a real worker AI suppression marker; suppression now survives crank block-entity disappearance and is recovered when the affected mob loads into a server world.

### Known platform differences

- Forge 1.20.1 does not provide NeoForge Data Maps or the NeoForge KubeJS event integration; canonical profiles are emulated by the Forge platform layer.

## NeoForge 1.21.1

This maintenance release completes the multi-version architecture introduced for Forge 1.20.1 while preserving the established NeoForge 1.21.1 behavior.

### Fixes

- Restored the original block-entity lifecycle ordering around Create's kinetic tick, including pre-tick redstone refresh and post-tick legacy direction resolution.
- Added worker reload grace periods so temporary entity/leash ordering during chunk or world reload does not destroy crank assignments.
- Corrected worker yaw to follow the actual orbit movement vector, prevented vanilla AI/navigation from fighting crank movement, and restored horse eating-animation suppression while working.
- Preserved NeoForge Data Map override/removal semantics while sharing canonical built-in worker and path definitions with Forge.
- Consolidated block and block-entity registration in common code and restored Flywheel visual/partial-model initialization.
- Fixed interaction, worker-tag layout, metadata, and cross-version resource/source parity regressions found during the Forge port.
- Replaced the temporary per-tick movement logger with a real worker AI suppression marker; suppression now survives crank block-entity disappearance and is recovered when the affected mob loads into a server world.

### Verification

- Both NeoForge 1.21.1 and Forge 1.20.1 compile, package, run the shared unit/parity suite, and pass required bootstrap plus real-horse orbit GameTests during aggregate verification.
