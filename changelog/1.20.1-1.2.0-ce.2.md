# Create Horse Power CE 1.2.0-ce.2 (Forge 1.20.1)

This release hardens the initial Forge 1.20.1 Community Edition port and aligns its default gameplay with NeoForge 1.21.1.

## Fixes

- Restored Flywheel crank visual registration and client partial-model initialization.
- Fixed empty-hand detachment so held items no longer remove attached workers.
- Corrected 1.20.1 entity tag resource paths.
- Matched canonical built-in worker and path profiles with NeoForge while retaining live legacy config behavior for legacy tags.
- Restored Create kinetic tick ordering and added safe worker reload grace periods.
- Corrected worker yaw to follow the actual orbit movement vector, prevented vanilla AI/navigation from fighting crank movement, and restored horse eating-animation suppression while working.
- Centralized shared registrations and strengthened source/resource parity checks to catch platform omissions.
- Added required Forge bootstrap and real-horse orbit GameTests and wired them into aggregate verification.
- Ported the Jade crank HUD provider and installed Jade in the Forge development client.
- Added an opt-in `debug.enableDebugLogging` server setting for rate-limited movement diagnostics; it defaults to `false`.

## Known platform differences

- Forge 1.20.1 does not provide NeoForge Data Maps or the NeoForge KubeJS event integration; canonical profiles are emulated by the Forge platform layer.
