# Create Horse Power - CE 1.21.1-1.1.0-ce.1

Initial release of **Create Horse Power - CE (Community Edition)** for **Minecraft 1.21.1 (NeoForge)**.

## Added
- **Data-Driven Worker Tiers**: Datapacks can now define and extend small, medium, and large workers via `#createhorsepower:workers/small`, `#createhorsepower:workers/medium`, and `#createhorsepower:workers/large`.
- **Bidirectional Rotational Power**: Cranks now support bidirectional power generation (`±1.0f` direction) to mesh seamlessly with existing Create kinetic networks.
- **Automated CI/CD Workflows**: Added automated GitHub Release and CurseForge publishing workflows.

## Fixed & Improved
- **Chunk Reload Worker Reconciliation**: Attached workers are persisted by UUID and world position in NBT; temporary chunk unloads no longer drop attachments or leak power (addresses upstream #22).
- **Adjacent Crank Stability**: Removed destructive kinetic state resets that caused adjacent cranks to destroy each other upon world reload (addresses upstream #25).
- **Leash Knot Ownership & Cleanup**: Replaced fuzzy bounding box queries with exact block-position knot matching. Breaking or detaching a crank cleanly unbinds the animal and drops exactly one lead without leaving ghost knot entities behind (addresses upstream #21).
- **1.21 Interaction Split**: Right-clicking with a lead attaches leashed mobs; right-clicking with an empty hand detaches. Non-lead tools (sticks, wrenches, weapons) no longer trigger accidental interactions.
- **Client & Goggles State Sync**: Synchronized worker resolution state across network packets so Create's Engineer's Goggles display accurate stress capacity and generation tooltips.
- **Modern 1.21.1 Resource Formats**: Updated recipe and loot table formats for 1.21.1 NeoForge.
