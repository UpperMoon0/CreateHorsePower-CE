# Create Horse Power - CE 1.21.1-1.2.2

## Fixed

- Fixed legacy/server balance precedence for bundled worker profiles. Modpacks that change the original Create Horse Power tier values now control the bundled worker base RPM and stress again instead of being shadowed by CE species defaults.
- Fixed TFG-style large-worker balance so `tfc:horse` respects configured tier output such as 16 RPM / 32 base SU instead of falling back to the bundled 5 RPM / 600 SU profile.
- Explicit legacy creature lists now win over CE tier fallbacks, preserving pack classifications such as TFG's custom TFC worker sizes.
- Fixed path precedence so pack-defined path data wins over CE bundled defaults.
- CE bundled worker and path defaults are no longer shipped as NeoForge Data Map entries. Data Maps now represent explicit datapack/packmaker overrides, while CE defaults resolve only as lower-priority common-code fallbacks.

## Preserved behavior

- KubeJS remains the highest-priority path/worker override layer.
- Explicit NeoForge Data Maps remain above legacy config and bundled defaults.
- Per-animal movement-speed and max-health scaling remains enabled and is still applied on top of the configured base worker output.
- Weighted mixed-path evaluation remains unchanged; only the per-block profile that feeds the weighted calculation now follows the corrected precedence.
- CE bundled worker/path defaults still apply when a pack does not provide an override.

## Effective path precedence

`KubeJS -> explicit NeoForge Data Map -> pack/server legacy path config -> CE bundled defaults`
