# Create Horse Power - CE 1.2.6

## Fixes

- Fixed NeoForge path output being applied twice after the `pathEvaluated` KubeJS hook. With no listener registered, a Great path could incorrectly turn a `2.0x` RPM multiplier into `4.0x` (and similarly square non-neutral stress multipliers).
- Defined `pathEvaluated` speed/stress values as final absolute path multipliers. Scripts can still replace them with `setSpeedMultiplier()` / `setStressMultiplier()`, but the crank no longer multiplies the returned values a second time.
- Preserved Forge behavior: the no-op script hook now returns the evaluator's existing path multipliers unchanged.

## Regression coverage

- Added real evaluator coverage for `LEGACY`, `WORST_BLOCK`, and `WEIGHTED_AVERAGE` with path stress scaling enabled and disabled.
- Added coverage proving RPM, validity, coverage accounting, and efficiency are unchanged when only path stress scaling is disabled.
- Added Forge 1.20.1 and NeoForge 1.21.1 crank GameTests for the production case: 16 base RPM / 32 base SU on a Great path keeps the `2.0x` RPM path bonus while final stress remains exactly 32 SU.
