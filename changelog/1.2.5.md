# Create Horse Power - CE 1.2.5

## Balance configuration

- Added `path.enableStressScaling` to control path-based stress-capacity scaling independently from path RPM scaling.
- The option defaults to `true`, preserving existing behavior for current worlds and modpacks.
- When disabled, path quality still controls RPM, validity, coverage, and path-efficiency behavior, but the path stress multiplier is fixed at `1.0` so a worker configured for 32 SU remains at 32 SU on Poor, Normal, or Great paths.
- `balance.enableIndividualAnimalStats` continues to control only animal movement-speed/max-health bonuses; path stress scaling is now explicitly configurable instead of being coupled to path quality.

## Verification

- Added regression coverage proving the default policy preserves the existing 0.90x/1.00x/1.10x path stress multipliers.
- Added regression coverage proving the disabled policy neutralizes Poor/Normal/Great path stress multipliers to 1.00x.
