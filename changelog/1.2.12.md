# Create Horse Power CE 1.2.12

## Gameplay
- Mixed tracks support unrecognized **solid, safely walkable** floor at zero contribution; holes, fluids, hazards and obstructed floors still invalidate the crank.
- Weighted-average, legacy and worst-block output accounts for unrecognized track coverage.
- Worker movement now samples the actual width of the worker; a persistent transient collision delays retries by 20 ticks, avoiding repeated kinetic/start-stop pulses.

## Upgrade
- Fresh server configs default to `minimumCoverage=0.0`. **Existing configs keep their saved value**, including `1.0`; change that setting explicitly to opt into forgiving mixed tracks.
- Do not install original Horse Power alongside CE.

## Validation
Both loader GameTests, Icy/Bionics compatibility and restart probes, and exact-SHA Jenkins acceptance remain mandatory before publication. This changelog is not a release approval.
