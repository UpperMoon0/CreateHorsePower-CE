# Create Horse Power CE 1.2.10

### Create: Bionics compatibility
- Add optional Oxhauler worker support for Forge 1.20.1 (Bionics source version 2.0.0) and NeoForge 1.21.1 (released Bionics 2.5.0), with no hard dependency in normal builds.
- Require complete assembly, fuel, and unoccupied/unsubmerged movement. Spend exactly one finite fuel unit per active crank tick and fail closed when the upstream setter fails.
- Exempt assembled robots from livestock-only taming policy; route NeoForge tool-part lead interactions through the normal player item lifecycle, retaining creative refunds and final survival lead destruction events.
- Upgrade NeoForge Create to 6.0.9, the minimum required by published Bionics 2.5.0.

### Verification and release limitations
- Add isolated two-loader real Bionics GameTests and a separate-process restart CI lane, with explicit mod-version, test-count, and evidence checks; normal installations remain Bionics-free.
- Forge 2.0.0 currently has upstream source code but no verified official published binary: CI builds the exact pinned source commit instead. This is **not** equivalent to verifying an official released Forge jar.
- Client multiplayer raycast and packet-level plough/harvester hitbox verification requires dedicated client acceptance; do not claim this is covered by headless server GameTests.
