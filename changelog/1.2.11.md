# Create Horse Power CE 1.2.11

### Forward-compatible dependency metadata
- Replace hard upper bounds on Create and exact-version restrictions on optional Icy's Better Horses with minimum-only loader ranges on Forge and NeoForge.
- Keep the minimum Create release at 6.0.8 and Icy API baseline at 2.1.7, without rejecting newer mod releases by version number alone.
- Preserve exact Minecraft target versions because the Forge and NeoForge artifacts are compiled against distinct game APIs. Existing Forge and NeoForge loader ranges were already minimum-only.
- Add a release-jar verifier requirement that **all non-Minecraft mod/loader dependencies have no upper bound**, including future declared dependencies.
- Update the opt-in Icy compatibility test artifacts to published 2.1.8 for both loaders; Gradle artifacts remain fixed for reproducible CI while runtime metadata stays open-ended.

### Verification
- On-prem-1 validation with published Icy 2.1.8 passed 32/32 required GameTests on **both Forge and NeoForge**, after changing the dependency metadata. Both loader builds, unit tests and release-jar dependency verifiers also passed.
- This policy permits future updates to load; it does not claim untested upstream API changes are compatible. CI and release acceptance must still exercise exact test binaries.
